# 品川→川崎 先着チェッカー

品川駅で「京浜東北線」と「東海道線（川崎方面）」、どちらに乗れば川崎に先に着くかをリアルタイムに判定するiPhone向けWebアプリ（PWA）です。

## 使い方

1. Safariでこのアプリの公開URLを開く
2. 「ホーム画面に追加」でアプリのように使える
3. 品川駅に着いたらアプリを開くだけで、次に来る京浜東北線・東海道線それぞれの川崎到着予想時刻と、どちらが早いかが表示される

## しくみ

- JR東日本の公式時刻表（https://timetables.jreast.co.jp/）から品川駅発の京浜東北線・東海道線の時刻を取得し、静的データ（`data/timetable.json`）として同梱
- 品川→川崎の所要時間は時間帯ごとに実際の列車時刻表から実測（ラッシュ時は停車時間が伸びるため時間帯別に補正）
- 現在時刻＋余裕時間（乗換・徒歩時間、デフォルト2分）を基準に、各路線の次発列車と川崎到着時刻を計算して比較

## データ更新について

JR東日本のダイヤは改正（主に3月）で変わることがあります。時刻がずれてきたら `data/timetable.json` を作り直してください。

## 開発

素のHTML/CSS/JavaScriptのみで依存ライブラリなし。`index.html` をそのままブラウザで開いても動作確認できます。

## 免責

このアプリの時刻は静的な時刻表データに基づく参考情報です。実際の運行状況（遅延・運休・臨時ダイヤ等）は反映されません。
