# 京浜東北線 vs 東海道線 先着チェッカー

上野・東京・新橋・品川・川崎・横浜のうち任意の2駅を選んで、京浜東北線・東海道線（・区間によっては京急線、横須賀線）のどれに乗れば先に着くかをリアルタイムに判定するiPhone向けWebアプリ（PWA）です。

## 使い方

1. Safariでこのアプリの公開URLを開く
2. 「ホーム画面に追加」でアプリのように使える
3. 出発駅・到着駅を選ぶと、各路線の次発列車と到着予想時刻、どれが早いかが表示される（到着が早い順に左から並び、画面に収まらない分は横スクロール）
4. 品川・川崎・横浜の組み合わせでは京急線、東京・新橋・品川・横浜の組み合わせでは横須賀線も比較対象に加わる

## しくみ

- JR東日本の公式時刻表（https://timetables.jreast.co.jp/）から各駅発の京浜東北線・東海道線・横須賀線の時刻を取得
- 京急電鉄は公式サイトがセッション依存で直接スクレイピングしづらいため、京急自身も時刻表データの提供元としてリンクしている駅探（https://ekitan.com/）経由で取得
- 区間ごとの所要時間は時間帯（JR）・種別（京急は普通/特急/快特で所要時間が大きく異なるため種別ごと）に実際の列車から実測して補正
- 行き先が短い列車（蒲田止まり・京急川崎止まり等）は、選んだ区間に届かない場合は自動的に候補から除外
- 現在時刻＋余裕時間（乗換・徒歩時間、デフォルト2分、-15〜+15分で調整可）を基準に、各路線の次発列車と到着時刻を計算して比較

## データ更新について

`scripts/build-timetable.js` がデータ生成を一括で行う。JR・京急ともにダイヤ改正で時刻が変わることがあるため、GitHub Actions（`.github/workflows/update-timetable.yml`）で月1回自動再生成している。手動更新する場合は `node scripts/build-timetable.js` を実行。

## 開発

素のHTML/CSS/JavaScriptのみで依存ライブラリなし。`index.html` をそのままブラウザで開いても動作確認できる。データ生成スクリプトはNode.js標準ライブラリのみで動作。

## 免責

このアプリの時刻は静的な時刻表データに基づく参考情報です。実際の運行状況（遅延・運休・臨時ダイヤ等）は反映されません。
